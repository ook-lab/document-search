# File Flattener (フォルダ内ファイル最上位集約ツール)

指定されたローカルフォルダ内のすべての階層にあるファイルを再帰的に探索し、それらをすべて指定されたフォルダの最上位（ルート）に移動させ、空になったサブフォルダを削除する Flask ベースの Web アプリケーションです。

## 💡 特長
*   **安全な Dry Run (プレビュー) 機能**: 実際に移動を実行する前に、どのファイルがどこへ移動されるかを画面上で確認できます。
*   **ファイル衝突の自動回避**: サブフォルダ内でファイル名が重複している場合、自動で末尾に連番 (`_1`, `_2`, ...) を付与して移動させるため、大切なデータの上書き消失を防ぎます。
*   **自動クリーンアップ**: 移動完了後、空になったサブフォルダ階層を深いディレクトリから順に安全に自動削除します（オプションでオフにすることも可能）。
*   **プレミアムUI**: グラスモルフィズムとダークテーマを取り入れたモダンで洗練されたデザイン。

## 🔧 動作要件
*   Python 3.x
*   Flask (プロジェクトの `requirements.txt` からインストール済み)

## 🚀 起動方法
1.  プロジェクトルートから、以下のコマンドで Flask サーバーを起動します。
    ```bash
    python apps/file-flattener/app.py
    ```
2.  ブラウザで以下のアドレスを開きます。
    *   [http://localhost:5005](http://localhost:5005)

## 📖 使い方
1.  **対象フォルダの指定**:
    画面の「対象のローカルフォルダパス」入力欄に、フラット化したいフォルダの絶対パスを入力します。
    *   例: `C:\Users\Username\Documents\test_folder`
2.  **スキャン (Dry Run)**:
    「スキャンする (Dry Run)」ボタンを押すと、移動予定のファイルが一覧として表形式でプレビュー表示されます。
    *   重複ファイルが存在する場合は、自動的に「重複回避リネーム」の警告バッジが表示され、リネーム後のファイル名が表示されます。
3.  **実行**:
    プレビューを確認して問題なければ、「フラット化を実行する」ボタンを押します。
    ファイルがすべて最上位に集約され、実行ログが表示されます。

## 🧪 テストの実行
バックエンドロジックの自動テストを実行するには、以下のコマンドを使用します。
```bash
python -m unittest apps/file-flattener/test_flattener.py
```
